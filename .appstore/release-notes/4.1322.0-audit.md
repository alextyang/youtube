# ImprovedTube 4.1322.0 release-note audit

This audit maps the App Store update text to the source changes between the
last published App Store version (`4.1321.0`) and the current publisher branch.
It deliberately excludes changes that are Firefox-only, test-only, formatting-
only, reverted, or already present in the published Safari build.
