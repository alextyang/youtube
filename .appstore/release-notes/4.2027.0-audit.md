# ImprovedTube 4.2027.0 release-note audit

This audit maps the App Store update text in [4.2027.0.md](4.2027.0.md) to source
changes and to reviewed Safari results. 4.1322.0 (build 1331) was uploaded but
never released, so the text covers everything since the last published version,
4.1321.0:

- changes in the held 4.1322.0 build, already audited in
  [4.1322.0-audit.md](4.1322.0-audit.md), at upstream `89d8a2ef`;
- upstream `code-charity/youtube` `89d8a2ef..9a156ee5` (64 commits, 2026-08-24 to 2026-10-11);
- publisher changes for this release.

**Verification basis.** Safari results come from the live feature inventory
(371 controls; 228 WORKING, 38 UPSTREAM BROKEN, 0 SAFARI BROKEN, 91 documented
UNKNOWN, 14 N/A). It ran on a Development-signed build, 4.1323.0 (1332), of this
same source; that build differs from the release only in its version string and
in the RES-01 packaging fix. Run IDs refer to the private monorepo's evidence.
Development receipts are inventory evidence, not release evidence. The processed
TestFlight build must still pass its own gate before submission.

**Policy.** The update text advertises only behavior with a reviewed WORKING
result. The exceptions are small upstream fixes that no inventory control
covers; those are marked "not inventoried". Anything the inventory found
UPSTREAM BROKEN is left out, even when an upstream PR claims it. UNKNOWN
behavior is also left out, unless the publisher accepts it explicitly (see
"Decisions needed").

## Decisions needed before submission

1. **Video Filters.** Advertise them only after someone confirms, on the
   TestFlight build, that a strong filter (for example a preset or high brightness)
   visibly changes the picture and that turning it off restores it. Without that
   check, leave them out of the text.
2. **App Privacy.** With Smart Speed enabled, the extension sends `sponsor.ajay.app`
   the first four hex digits of the SHA-256 of each watched video ID. The fetch
   carries no cookies, but the server sees the IP address and user agent.
   Smart Speed also fetches the YouTube watch page without cookies. Decide how
   App Store Connect's privacy answers describe this. The update text already
   names SponsorBlock.
3. **Version number.** 4.2027.0 follows upstream's release numbering (v4.2027).
